# Names for G.EXE, by hand.
#
# One symbol a line:   <address>  <kind>  <name>  ; what it is
#
#   kind f  a function, or a state routine (an entity's per-tick code,
#           installed with set_state) — Ghidra gets a function there
#   kind d  data: a global, a table, an object template
#
# Addresses are virtual addresses in the mapped LE image, the same ones
# scripts/formats/README.md quotes. Everything here was read off the code;
# a name that is only a guess says so in its comment ("?").
#
# symbols.py adds names it can derive from the binary itself — class
# constructors from the registry, templates by their sprite, states by
# their template — and a name here wins over a derived one.
#
#   python3 scripts/ghidra/symbols.py table      merged list for Ghidra
#   python3 scripts/ghidra/symbols.py coverage decomp.c
