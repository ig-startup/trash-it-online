# User Spec: Trash It Online — браузерный мультиплеер

## Что делаем

Браузерная онлайн-версия классической DOS-игры Trash It (1997). Строители бегают по 2D-уровням, ломают постройки молотком и добираются до колокольчика. До 4 игроков играют вместе через интернет с любого устройства — без установки, по ссылке.

## Зачем

Оригинальная игра поддерживает только мультиплеер за одним компьютером. Хочется играть с братьями онлайн — с Mac и с Windows одновременно, находясь в разных местах.

## Как должно работать

**Сценарий: создать и начать игру**

1. Игрок открывает сайт в браузере
2. Выбирает режим: **Кооп** (пройти уровень вместе) или **Соревнование** (кто первый добежит до колокольчика)
3. Нажимает «Создать комнату» — получает короткий код (например, `XKCD`)
4. Делится кодом с братьями в любом мессенджере
5. Братья открывают сайт, вводят код — попадают в ту же комнату
6. Когда все готовы — хост запускает игру
7. Все видят один и тот же уровень, управляют своим персонажем
8. В кооп-режиме: все вместе добираются до колокольчика до истечения таймера
9. В режиме соревнования: кто первый ударит в колокольчик — победитель

**Механики персонажа:**
- Бег влево / вправо
- Прыжок
- Приседание / проползание под каской
- Удар молотком (ломает объекты, активирует механизмы)
- Взаимодействие с объектами (передвижение)

**Уровни:**
- Воссоздание оригинальных уровней из Trash It 1997
- Платформы, балки, разрушаемые объекты, механизмы
- Колокольчик как цель уровня

## Критерии приёмки

- [ ] Игра открывается в браузере на Mac (Chrome/Safari) и Windows (Chrome/Edge) без установки
- [ ] Можно создать комнату и подключиться по коду с другого устройства
- [ ] До 4 игроков одновременно в одной комнате
- [ ] Персонаж реагирует на управление без заметных задержек (< 100 мс)
- [ ] Позиции всех игроков синхронизированы на всех экранах
- [ ] Реализован хотя бы 1 полноценный уровень из оригинала
- [ ] Работают оба режима: кооп и соревнование
- [ ] Таймер на уровне — при истечении уровень проигран
- [ ] При ударе в колокольчик уровень завершается корректно

## Ограничения

- Кроссплатформенность: работает в современных браузерах без плагинов
- Оригинальные уровни закрыты бинарными форматами — нужно воссоздавать вручную или реверс-инжинирить
- Без регистрации и авторизации — игра по временным комнатам
- Сервер должен держать несколько одновременных комнат

## Риски

- **Риск: бинарный формат уровней** — файлы `.G2`, `.OB`, `.WAM` из оригинала не задокументированы. **Митигация:** воссоздавать уровни вручную по скриншотам / видео оригинала, начать с одного уровня.
- **Риск: сетевая задержка** — при плохом соединении персонажи будут «прыгать». **Митигация:** клиентская предикция движения (двигаем локально сразу, синхронизируем с сервером).
- **Риск: разные браузеры** — поведение Canvas и физики может отличаться. **Митигация:** тестировать на Chrome и Firefox с первого дня.

## Технические решения

- Используем **Phaser.js** — готовая физика, спрайты, ввод, достаточно для 2D-платформера без написания движка с нуля.
- Используем **Node.js + Socket.io** — реалтайм WebSockets, проверенный стек для браузерных мультиплеерных игр.
- Хостинг на **Railway** — деплой за 5 минут, бесплатный тариф для старта.
- Авторизации нет — идентификация по случайному ID сессии.

## Тестирование

**Unit-тесты:** делаются для игровой логики — коллизии, таймер, условия победы/поражения.

**Интеграционные тесты:** делаем — проверяем Socket.io события: подключение, синхронизация позиций, завершение уровня.

**E2E тесты:** не делаем на MVP — слишком дорого для игры, проверяем руками.

## Как проверить

### Агент проверяет

| Шаг | Инструмент | Ожидаемый результат |
|-----|-----------|-------------------|
| 1. Сервер стартует | `npm start` | Логи: `Server listening on port 3000` |
| 2. Создание комнаты | curl POST /room/create | JSON с кодом комнаты из 4 символов |
| 3. Подключение второго игрока | Socket.io client | Оба клиента получают событие `player_joined` |
| 4. Синхронизация движения | Jest + socket mock | Позиция игрока обновляется у всех в комнате |
| 5. Завершение уровня | Jest | При `bell_hit` все получают `level_complete` |

### Пользователь проверяет

- Открыть на Mac и Windows одновременно → создать комнату → подключиться → убедиться что видят друг друга
- Пройти до колокольчика → проверить что экран победы показывается у всех
- Проверить плавность движения при реальном подключении через интернет
