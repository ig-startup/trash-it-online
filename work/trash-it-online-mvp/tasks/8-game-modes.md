# Task 8: Режимы игры — кооп и соревнование

## What to do

Подключить логику режимов игры на клиенте: кооп (все достигают цели вместе) и гонка (кто первый ударит в колокольчик). Обработать события завершения уровня от сервера. Добавить визуальную индикацию режима на экране.

## Context Files

- `work/trash-it-online-mvp/tech-spec.md`
- `shared/constants.js`
- `client/src/scenes/GameScene.js`
- `server/src/GameRoom.js`

## Test-Driven Development

Режимы тестируются в GameRoom (уже покрыто в T6). На клиенте — визуальная проверка.

## Implementation Steps

1. Обновить `client/src/scenes/GameScene.js`:
   - В `init(data)` сохранить `this.mode` ('coop' | 'race')
   - Показать режим в HUD: текст "КООП" или "ГОНКА" вверху экрана
   - Обработчик `level_complete`:
     - В race с winnerId === playerId → показать "ВЫ ПОБЕДИЛИ!"
     - В race с другим winnerId → показать "Победил [имя]"
     - В coop с winnerId=null → показать "КОМАНДА ПОБЕДИЛА!"
     - Через 3 секунды → переход в MenuScene
   - Обработчик `level_failed`:
     - Показать "ВРЕМЯ ВЫШЛО" + "ПОРАЖЕНИЕ"
     - Через 3 секунды → переход в MenuScene

2. В coop: визуально отображать прогресс (кто ближе к колокольчику) — опционально для MVP

3. Убедиться что в race режиме после bell_hit первого игрока остальные не могут нажать колокольчик повторно (сервер не должен обработать повторный bell_hit после level_complete)

## Verification Steps

1. Создать комнату в режиме "Кооп", пройти до колокольчика, ударить
   - Expected: все игроки видят "КОМАНДА ПОБЕДИЛА!"
2. Создать комнату в режиме "Гонка", первый игрок достигает колокольчика
   - Expected: победитель видит "ВЫ ПОБЕДИЛИ!", другие "Победил [имя]"
3. Дождаться таймаута (или временно уменьшить timeLimit)
   - Expected: все видят "ВРЕМЯ ВЫШЛО"
4. После экрана результата через 3 секунды переход в меню
   - Expected: оба браузера возвращаются в MenuScene
