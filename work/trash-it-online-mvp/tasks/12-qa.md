# Task 12: QA на Mac + Windows

## What to do

Финальная ручная проверка всех критериев приёмки на реальных устройствах через интернет.

## Context Files

- `work/trash-it-online-mvp/user-spec.md` — критерии приёмки

## Чеклист проверки

### Устройства
- [ ] Mac: Chrome
- [ ] Mac: Safari
- [ ] Windows: Chrome
- [ ] Windows: Edge

### Сценарий 1: Базовый мультиплеер
- [ ] Открыть сайт на Mac и Windows одновременно
- [ ] На Mac создать комнату в режиме "Кооп"
- [ ] На Windows войти по коду
- [ ] Оба видят друг друга в лобби
- [ ] Хост нажимает Старт
- [ ] Оба попадают в игру

### Сценарий 2: Геймплей
- [ ] Персонаж двигается без заметных задержек (< 100мс ощущение)
- [ ] Позиции игроков синхронизированы
- [ ] Платформы, прыжок, приседание — всё работает
- [ ] Удар молотком разрушает объекты
- [ ] Таймер отображается и убывает

### Сценарий 3: Завершение уровня
- [ ] Кооп: оба добираются до колокольчика, один бьёт → победа для всех
- [ ] Гонка: первый бьёт → победа ему, поражение другим
- [ ] Таймаут → поражение для всех

### Сценарий 4: Устойчивость
- [ ] Один игрок закрывает вкладку — второй получает уведомление
- [ ] Игра не падает при дисконнекте одного из игроков

## Acceptance Criteria

- [ ] Все сценарии пройдены без критических багов
- [ ] Задержка управления < 100мс при нормальном интернете
- [ ] Нет JS-ошибок в консоли в обычном геймплее
