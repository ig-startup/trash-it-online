# Task 9: UI-оверлеи — таймер, победа/поражение

## What to do

Реализовать игровой HUD: таймер обратного отсчёта, список игроков с индикаторами, и полноэкранные оверлеи победы/поражения. Все элементы должны быть закреплены на экране (не двигаться с камерой).

## Context Files

- `client/src/scenes/GameScene.js`
- `shared/constants.js`

## Test-Driven Development

UI не тестируется unit-тестами. Проверка визуальная.

## Implementation Steps

1. Добавить HUD в `GameScene.js` (все элементы с `setScrollFactor(0)` — не движутся с камерой):
   - Таймер: крупный текст в центре сверху, красный при < 30 секунд
   - Список игроков: иконки с именами слева сверху (цветной квадрат + имя)
   - Режим: текст "КООП" / "ГОНКА" справа сверху
   - Обработчик `timer_tick` → обновлять текст таймера

2. Создать оверлей победы (полупрозрачный тёмный фон + текст):
   - Функция `showVictoryOverlay(message)` — принимает строку
   - Большой текст с результатом (ПОБЕДА / ПОРАЖЕНИЕ)
   - Подтекст с деталями
   - Таймер обратного отсчёта "Возврат в меню через 3..."

3. Создать оверлей поражения:
   - Функция `showDefeatOverlay(reason)` — reason: 'timeout'
   - Тот же стиль что и победа, другой текст

4. Обновить обработчики из T8 — использовать эти функции

5. Добавить паузу при потере фокуса браузера (опционально):
   - При `blur` показывать текст "Пауза", при `focus` убирать

## Verification Steps

1. Запустить игру — в HUD виден таймер, имена игроков, режим
2. Таймер убывает каждую секунду
3. При < 30 секунд таймер становится красным
4. Победа → виден тёмный оверлей с текстом результата
5. Поражение → виден тёмный оверлей с "ВРЕМЯ ВЫШЛО"
6. Двигать персонажа — HUD остаётся на месте (не двигается с камерой)
