# Trash It Online

Браузерная онлайн-версия DOS-игры **Trash It** (1997). Строители бегают по
2D-уровням, ломают постройки молотом и добираются до колокольчика. До 4
игроков по ссылке, с любого устройства — оригинал умел мультиплеер только
за одной клавиатурой.

## Структура

| Папка | Что внутри |
|---|---|
| `client/` | Игра в браузере — Phaser 3 + Vite |
| `server/` | Node.js + Express + Socket.io — комнаты, синхронизация |
| `shared/` | Общее для обеих сторон: события, конфиг, порядок уровней |
| `scripts/` | Декодеры форматов оригинала и экспортёры ассетов — см. `scripts/README.md` |

Запуск: `npm install && npm run dev` в `client/` и `server/`.
Деплой — `DEPLOYMENT.md`.

## Ассеты и права

Графика и уровни — из оригинальной игры 1997 года. Они не нарисованы
заново: `scripts/formats/` содержит декодеры её бинарных форматов
(`.SPR`, `.G2`, `.WAM`, `.SCN`, `.OBT`, `.PAL`), разобранных из самой игры,
а экспортёры в `scripts/` превращают их в PNG для клиента.

**Trash It © 1997 Atari.** Использование ассетов — по письменному
разрешению Atari Licensing Department на некоммерческое воссоздание игры.
Проект некоммерческий. Сами файлы оригинальной игры в репозиторий не
попадают (`Trash-it-original/` в `.gitignore`) — экспортёры работают с
локальной копией.
